### 👋 About me

I'm the COO at **Triumph Capital Management**, an SEC-registered investment adviser, and I build the systems that run the firm. My work sits where operations, compliance and data meet: I take the manual, spreadsheet-and-email parts of running an advisory firm and turn them into tools that run themselves every morning.

- 🏛️ **Operations first.** I build for the people doing the work: advisors, operations and compliance.
- 🔒 **Data stays put.** Client data never touches a repo. Code ships, records stay in the system of record.
- ⏱️ **Automate the morning.** If it happens every day, it should be scheduled, logged and checked.
